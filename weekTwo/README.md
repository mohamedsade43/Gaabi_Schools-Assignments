# Mohamed Abdirisaq — Developer Profile

A clean, modern, and responsive personal profile website built with HTML and CSS. The website introduces my background, showcases the technologies I am learning, and provides links to my contact information and professional profiles.

## 🌐 Project Overview

This project is a personal developer profile designed to present my identity as a software developer and technology educator. It features a profile sidebar, an About Me section, a technology learning section, and contact links in a simple and professional layout.

## ✨ Features

- **Personal Profile:** Profile picture, name, and professional introduction.
- **About Me:** A short description of my background and goals.
- **Learning & Skills:** Cards highlighting HTML, CSS, JavaScript, React, and full-stack development.
- **Contact Information:** Email, GitHub, and website links.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **Font Awesome Icons:** Visual icons for navigation, contact links, and technologies.
- **Google Fonts:** Uses the Roboto typeface for clear and readable text.

## 🛠️ Technologies Used

| Technology | Purpose |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Open the project

```bash
cd developer-profile
```

### 3. Run the website

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code for local development.

No build tools or package installation are required.

## 📱 Responsive Design

The website uses CSS Grid, Flexbox, and media queries to adapt the layout to different screen sizes.

- **Desktop:** Profile sidebar and main content appear side by side.
- **Tablet:** Layout and spacing adjust to the available width.
- **Mobile:** Profile information, About Me, and skill cards stack vertically for easier reading.
